# Roadmap

The current release supports native callback timing, binary streaming, local browser analysis, headless queries, configurable capture scope and triggered recording. See the [README](../README.md) for features and measurement limits.

Planned work:

- Broader Repentance+ / REPENTOGON compatibility testing and release validation.
- Reproducible demo recordings that can be redistributed with the project.
- Matched A/B captures and an independent baseline for profiler overhead.
- Incremental live summaries during recording, with bounded recent history.
- More precise engine/GC execution and allocation attribution where instrumentation permits.
- UI text-size controls and an optional in-game overlay.

These are development directions, not promised release dates.
